# New Balan Delivery – Flutter Setup

## 1. Scaffold the Flutter project (one-time)

Flutter's Android / iOS project directories are generated by the CLI.
Run this command **in the `new_balan_delivery_flutter/` folder**:

```bash
flutter create . --project-name new_balan_delivery --org com.newbalan.medical --platforms android,ios
```

This creates the Android / iOS scaffolding.  
All `lib/` files and `pubspec.yaml` from this directory are then used as-is.

---

## 2. Install dependencies

```bash
flutter pub get
```

---

## 3. Configure the API origin

The project root `.env` uses the same `VITE_API_BASE_URL` and `VITE_API_PREFIX` as **new_balan_fe** (loaded via `flutter_dotenv`).  
If `.env` is missing, the default API host is `http://10.0.2.2:8000` (Android emulator → host machine).

Override at build/run time with `--dart-define` (wins over `.env`):

```bash
# Android emulator (default)
flutter run

# Physical device on the same Wi-Fi
flutter run --dart-define=API_ORIGIN=http://192.168.1.x:8000

# Production
flutter run --dart-define=API_ORIGIN=https://api.newbalan.example.com
```

## 4. Android – update build.gradle files

After `flutter create`, open `android/app/build.gradle` and ensure:

```groovy
android {
    compileSdkVersion 34
    defaultConfig {
        minSdkVersion 21          // required for flutter_secure_storage
        targetSdkVersion 34
        ...
    }
}
```

## 5. Push notifications (FCM) – required

Push notifications use Firebase Cloud Messaging. Firebase is already wired up in
`main.dart`, `notification_provider.dart`, and `pubspec.yaml`. You only need to
supply the platform config files and run `flutterfire configure`.

### Setup steps:
1. Create a project at [Firebase Console](https://console.firebase.google.com)
2. Add an Android app with package ID `com.newbalan.medical.delivery`
3. Download `google-services.json` → place in `android/app/`
4. Add an iOS app with bundle ID `com.newbalan.medical.delivery`
5. Download `GoogleService-Info.plist` → place in `ios/Runner/`
6. Install the FlutterFire CLI and run:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure --project=<your-firebase-project-id>
   ```
   This regenerates `lib/firebase_options.dart` with real values.
7. On the Firebase Console → Project Settings → Service Accounts, generate a
   new private key (JSON). Place it on the backend server and point
   `GOOGLE_APPLICATION_CREDENTIALS` (or `GCS_CREDENTIALS_PATH`) at it.

---

## 6. Run

```bash
# Debug
flutter run

# Release APK
flutter build apk --release --dart-define=API_ORIGIN=https://your-api.com

# Release AAB (for Play Store)
flutter build appbundle --release --dart-define=API_ORIGIN=https://your-api.com
```

## Project structure

```
lib/
├── main.dart                  # App entry, providers
├── app.dart                   # GoRouter + MaterialApp.router
├── config.dart                # API origin / URL builder
├── theme/
│   └── app_theme.dart         # Color palette + ThemeData (matches RN app)
├── models/
│   ├── auth_models.dart       # AuthUser, MenuItem, LoginResponse, StoredAuth
│   ├── order_models.dart      # OrderRow, OrderItemRow, OrderDetailResponse
│   └── notification_models.dart
├── services/
│   ├── api_client.dart        # HTTP wrapper (get/post/patch + auth header)
│   ├── auth_service.dart      # login, permissions, changePassword, logout
│   ├── orders_service.dart    # getAssignedOrders, getOrderDetail, updateOrder
│   ├── users_service.dart     # updateUserProfile
│   └── notifications_service.dart
├── utils/
│   ├── secure_storage.dart    # flutter_secure_storage wrapper
│   ├── order_lifecycle.dart   # Status labels + allowed-action logic (mirrors RN)
│   ├── permissions.dart       # hasModuleGrant (mirrors RN lib/permissions.ts)
│   └── device_id.dart         # Stable per-install UUID
├── providers/
│   ├── auth_provider.dart     # ChangeNotifier: login/logout/restore/updateLocalUser
│   └── notification_provider.dart
└── screens/
    ├── login_screen.dart
    ├── main_shell.dart        # Bottom-tab scaffold + bell icon
    ├── deliveries_screen.dart # Active orders
    ├── history_screen.dart    # Completed/returned orders
    ├── profile_screen.dart    # Profile edit + password change + sign out
    ├── order_detail_screen.dart
    ├── notifications_screen.dart
    └── widgets/
        └── order_card.dart    # Reusable order-list card
```
